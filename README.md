# Опа

Переключатель раскладки для macOS в духе Punto Switcher и Caramba. Исправляет текст, набранный не в той раскладке (EN ⇄ RU), по двойному Shift или своему сочетанию клавиш переводит слово или выделение, а по желанию исправляет и опечатки. Название — то, что говоришь, увидев `ghbdtn` вместо «привет».

Бесплатно, открытый код, всё работает на компьютере.

*English: Opa is a free, open-source keyboard layout switcher for macOS (English ⇄ Russian). It fixes words typed in the wrong layout as you type, converts the last word or the selection on a double Shift or a custom hotkey, and can optionally fix common typos. Everything runs locally.*

## Установка

1. Скачайте `Opa-<версия>.dmg` со страницы [Releases](../../releases/latest) и перетащите «Опа» в «Программы».
2. Первый запуск. Приложение не нотаризовано Apple (для этого нужен платный аккаунт разработчика), поэтому macOS его остановит. Откройте **Системные настройки → Конфиденциальность и безопасность** и внизу, у сообщения про «Опа», нажмите **«Всё равно открыть»**. Или в Терминале: `xattr -dr com.apple.quarantine /Applications/Опа.app`.
3. Дайте доступ: **Конфиденциальность и безопасность → Универсальный доступ → Опа**. Без него приложение не видит нажатий, в строке меню будет `⚠︎`. Если значок не сменился на `EN`/`RU`, включите «Опа» ещё и в разделе «Мониторинг ввода».
4. Нужны раскладки **ABC** (или US) и **Русская** (подойдёт и «Русская – ПК»).

Доступ привязан к подписи: обновления, подписанные тем же сертификатом, его сохраняют.

## Что умеет

- **Автопереключение.** После пробела, Enter или Tab проверяет последнее слово. Если оно набрано не в той раскладке (`ghbdtn` → «привет», `руддщ` → `hello`), стирает его, печатает правильно и переключает раскладку. Заглавная, задержанная на букву дольше, не мешает: `GHbdtn` → «Привет».
- **Двойной Shift** (два коротких нажатия подряд) или **своё сочетание клавиш** (меню → «Задать сочетание клавиш…», например ⌃⌥Z или F13) срабатывает всегда, независимо от того, верно ли набрано слово:
  - если выделен текст — переводит выделение в другую раскладку;
  - сразу после автозамены или исправления опечатки — отменяет его, и слово больше не будет исправляться автоматически;
  - сразу после вставки (⌘V) — переводит весь вставленный текст. Сам вставленный текст автозамена не трогает;
  - иначе — переводит слово у курсора (курсор внутри слова — всё слово целиком) вместе с отложенной буквой перед ним: `d ujhjlt` → «в городе». К нужному слову можно вернуться стрелками ←/→: приложение отслеживает курсор само. После клика мышью слово читается из поля через Accessibility. Повторный двойной Shift возвращает как было;
  - VS Code, Chrome, Slack и другие приложения на Chromium не отдают текст поля через Accessibility. После клика или выделения мышью текст там берётся через буфер обмена: ⌘C (если что-то выделено), иначе ⌘⇧← и ⌘C — строка до курсора, → снимает выделение. Буфер обмена потом возвращается как был. Так бывает, только если в этом приложении недавно печатали и это не терминал;
  - если переводить нечего — просто переключает раскладку.
- **Опечатки** (выключено по умолчанию, включается в меню). После пробела исправляет незнакомое слово с типичной опечаткой быстрого набора: две буквы местами (`првиет`, `teh`), пропущенная буква (`спасбо`), лишняя (`приввет`, `untill`), соседняя клавиша (`чтобв`), две заглавные в начале («ПРивет»). Перепутанная гласная (`превет`, `definately`) — только если так же исправляет системная проверка орфографии.
- **Меню в строке меню:** включить или выключить каждую функцию, задать сочетание клавиш, отключить автоматические исправления в текущем приложении (например, в терминале), забыть слова-исключения, автозапуск при входе.

Автопереключение исправляет только слово, которое набрано с клавиатуры в конце строки. После Enter, клика, ↑/↓ или сочетания с ⌘/⌃/⌥ отслеживание начинается заново.

## Приватность

- В сеть ничего не уходит: приложение не делает ни одного сетевого запроса.
- Набранный текст никуда не записывается. В системный журнал попадают только служебные сообщения (перехват запущен, нет доступа), без текста.
- Буфер обмена читается только по двойному Shift (или своему сочетанию) в приложениях, которые не отдают текст поля, и сразу возвращается как был. Менеджеры истории буфера обмена (Raycast, Paste) могут успеть запомнить эту временную копию.
- В полях паролей macOS включает «защищённый ввод», и нажатия до приложения не доходят.

## Как работает распознавание

Одни и те же нажатия читаются в обеих раскладках. Потом сравнивается, какой вариант больше похож на слово:

1. Частотные словари (~48 тыс. слов на язык, `Resources/en.txt`, `Resources/ru.txt`) и системная проверка орфографии (понимает падежи и формы).
2. Для незнакомых слов — триграммная модель: насколько сочетания букв типичны для языка.
3. Спорные случаи. Слово из одной буквы (`z` → «я») или слово, которое есть в обоих языках, откладывается до следующего слова. Если следующее исправлено, исправляется и отложенное: `z ljvf` → «я дома». Если предыдущее слово набрано верно на этом языке, спорное не трогается: `React vs Vue` остаётся как есть.

Проверка на 20 тыс. самых частых слов каждого языка: ложных срабатываний 0%, распознано 99,9% слов, набранных не в той раскладке.

## Как исправляются опечатки

Слово исправляется, только если его не знает системная проверка орфографии. Кандидаты — слова на расстоянии одной типичной ошибки, которые есть в частотном словаре и которые знает проверка орфографии (так отсекаются имена и ошибки из субтитров). Первая буква не меняется никогда.

Слово не трогается, если:

- похожих вариантов несколько (`жизн` — «жизнь» или «жизни»?). Неверное исправление хуже опечатки: настоящее слово проверка орфографии уже не подчеркнёт;
- система исправляет в другое знакомое слово (`таска` → «маска»);
- слово с заглавной, а вариант не из 5 тыс. самых частых (скорее всего, это имя);
- в слове меньше трёх букв, есть цифры, знаки внутри, ЗАГЛАВНЫЕ или CamelCase;
- слово вставлено из буфера обмена.

Короткие слова исправляются только в частые: у них много соседей в словаре. По Enter опечатки не исправляются: сообщение уже может уйти, и откатить исправление будет нельзя.

На проверке из синтетических опечаток в частых словах исправлено ~70%, неверно ~1,3%. На ~500 словах IT-жаргона, сленга и имён 4 ложных исправления: `чот`, `aws`, `oauth`, `systemd`. Такое слово достаточно один раз вернуть двойным Shift.

## Ограничения

- Только пара латиница/кириллица (EN/RU).
- Если приложение само меняет текст (автодополнение, автозамена), исправление может стереть не те символы. В таком приложении отключите автоматические исправления через меню.
- Исправление опечаток не знает контекста. Редкое слово или жаргон иногда превращается в похожее частое слово. Двойной Shift сразу после исправления возвращает слово и запоминает его.
- В VS Code, Chrome и других приложениях на Chromium после клика, если курсор стоит посреди слова, переводится только часть до курсора.
- Иногда раскладка после автозамены не переключается. Двойной Shift это исправляет.

## Если что-то пошло не так

Выход из меню сразу возвращает клавиатуру к обычной работе: после этого нажатия никто не перехватывает.

Опишите, в каком приложении, что набирали и что получилось, — в [Issues](../../issues) или через меню → «Сообщить о проблеме…».

## Сборка из исходников

Нужны macOS 13+ и Xcode (или Command Line Tools).

```bash
./build.sh run       # собрать build.noindex/Опа.app и запустить
./build.sh install   # собрать, положить в /Applications и запустить
./build.sh release   # для Apple Silicon и Intel, упаковать в dist/Opa-<версия>.dmg
```

`build.sh` подписывает приложение одним и тем же сертификатом, чтобы доступ «Универсальный доступ» не слетал после пересборки. Для своих сборок — из `SIGN_IDENTITY` или файла `.sign-identity` (имя сертификата одной строкой), по умолчанию первый найденный «Apple Development»; нет никакого — подпись ad-hoc, и доступ придётся выдавать после каждой сборки. Релиз подписывается сертификатом «Opa Release» (`tools/make-release-cert.sh` создаёт его один раз): в «Apple Development» вшит email автора. После смены сертификата доступ нужно выдать заново: `tccutil reset Accessibility com.opa.switcher`.

Самоподписанный сертификат можно сделать и руками: «Связка ключей» → «Ассистент сертификации» → «Создать сертификат…», тип удостоверения — «Самоподписанный корневой», тип сертификата — «Подпись кода». Если `codesign` его не находит, откройте сертификат → «Доверие» → «Подпись кода: Всегда доверять».

## Версии

Номер версии — `X.Y.Z`: X — несовместимые изменения, Y — новые возможности, Z — исправления. Он записан в `Resources/Info.plist` (`CFBundleShortVersionString` и `CFBundleVersion`). Метка релиза — `vX.Y.Z`, файл — `Opa-X.Y.Z.dmg`.

## Код

- `Sources/SwitcherCore` — логика без UI: раскладки (`KeyboardLayout`), движок строки (`LineEngine`), распознавание (`Detector`, `LanguageModel`), опечатки (`TypoCorrector`).
- `Sources/Opa` — приложение: перехват клавиш на отдельном потоке (`EventTap`, `TapThread`), печать исправлений (`KeyPoster`), поле ввода через Accessibility (`Selection`) и буфер обмена (`ClipboardText`), сочетание клавиш (`Hotkey`, `HotkeyWindow`), меню (`AppDelegate`).
- `tools/make-icon.swift` — иконка (инструкция в начале файла).
